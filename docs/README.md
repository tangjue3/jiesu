## 约定

- 报告里的判断分三档：**实测**（有代码有输出）/ **推断**（有依据未验证）/ **假设**（待验证）。不要把推断当实测引用。
- 推翻旧结论时，**保留原文并标注被推翻**，而不是直接改掉——否则下一个人会重复踩。
- 每份报告的结论都要能在 `jiesu/spikes/` 里找到可重跑的证明。
